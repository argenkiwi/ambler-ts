The ATP CLI (specs/cli.md, walks/cli.ts) is one walk: CLI_ROUTE consumes argv[0] and fans out to SCAFFOLD_NODE/WALK/UTIL, RUN_CHECKS, CLI_HELP, CLI_ERROR. Nodes never call process.exit; they set state.exitCode (2 usage, 1 already-exists, child code for checks) and the root cli.ts shim exits with it, so every path is testable with injected fakes (nodes/tests/fake-fs.ts). Expected failures take onError, which the walk wires to null because the node already printed and set the code. Pure name-casing and source templates live in utils/naming.ts and utils/templates.ts; ScaffoldUtils (utils/fs.ts) is shared by the three scaffolders. Gotcha: inside a generic NodeFactory, a helper returning {...state, exitCode} must not annotate its return as State (it is S, not State) or tsc fails. The walk `--no-runner` flag is still a parsed no-op, preserved from the original script; ambler delegates to this CLI so exit codes must not change.
