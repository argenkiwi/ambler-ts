`bun run ambler check` runs the `todo` convention (utils/conventions.ts) over nodes/, walks/ and utils/ (tests included) before tsc, Biome and tests, with or without --lint-only. It matches the exact code the scaffolders emit, `throw new Error("not yet implemented")`, `.toThrow("not yet implemented")` and `unwired("NODE.onEdge")` with a literal edge, by regex rather than an AST, because TypeScript has no parser at runtime without depending on `typescript`. Because check runs on ambler-ts itself, its own source must never contain those forms literally: templates.ts interpolates NOT_IMPLEMENTED, the `unwired("${id}")` template is skipped because of the `$`, and tests build expected strings with a helper that must not itself be named `unwired` (a call `unwired("X.onY")` to a test helper is indistinguishable from the placeholder). Generated node tests assert `.toThrow("not yet implemented")`, so they pass while the body is unfinished; the rule is what makes unfinished nodes fail `check`.
