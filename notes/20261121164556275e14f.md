Ported from ambler-rs (Walk::run plus inline walk wiring tests). Every walk exports State, NodeId, WalkUtils and createWalk(utils), where WalkUtils is a partial map of per-node Utils overrides passed as each factory's second argument (undefined falls back to defaultUtils). The import.meta.main block just calls walk(createWalk(), START, initial) from ambler.ts, which replaces the hand-copied while/instanceof Promise loop, returns the final state, and wraps any throw in WalkError(nodeId, cause). That is what makes walks/tests/*.test.ts possible: one scripted mock set drives the whole graph. Utils types are pulled in with separate `import type` lines so `import defer` still defers the node modules. What was deliberately NOT ported: Rust outcome enums and exhaustive match. TS already gets the same guarantee because Record<E, N|null> makes every edge required and Record<K, ...> makes every node id required. The NodeFactory type also gained an optional 4th type param O (options as the factory's 3rd arg), mirroring Rust Confirm::new(question), so one generic node can sit under several ids.
