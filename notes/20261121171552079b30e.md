The init and clone walks (walks/init.ts, walks/clone.ts, their init-*/clone-* nodes, specs and tests) and the ambler-init agent skill were removed on 2026-11-22. Generating projects and copying walks/nodes/utils between projects will be handled by external tooling, so ambler-ts now holds only the engine (ambler.ts), the example walks (counter, chat) and the authoring skills (spec, node, test, walk, util). Dropping ambler-init also removed its assets/ copy of ambler.ts, which had to be kept in sync by hand. Do not re-add scaffolding walks or scripts here; point users to the external tool instead.
