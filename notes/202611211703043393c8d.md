ambler-ts moved from Deno to Bun (1.4.5) ahead of Deno maintenance ending Oct 2027. Bun 1.4+ parses AND genuinely defers `import defer` (verified: the deferred module evaluates on first property access), and TypeScript 7 type-checks it, so walks keep it; Bun 1.2.x cannot parse it, so 1.4 is the floor. The editor language server may still flag the syntax; tsc 7 and Bun are the source of truth. Default Utils use node:fs/promises and process.* rather than Bun.* so nodes stay portable to Node. Node Stats.isDirectory is a method, so when a node needs it, adapt Utils.stat to return a plain { isDirectory: boolean } to keep mocks trivial; test mocks fake a missing path with an Error carrying code ENOENT. Projects use package.json (scripts + dependencies) and tsconfig.json instead of deno.json; runtime imports of utils belong in dependencies, not devDependencies. (The init/clone walks that generated these files were later removed; see the linked note.) Accepted losses: Bun has no --allow-* sandbox, and Bun stricter expect typings reject toEqual(undefined), so use toBeUndefined(). Behaviour gain: Bun prompt() reads piped (non-TTY) stdin, where Deno prompt() returned null immediately, so scripted runs like printf 7 | bun run counter now work. Tooling: bun:test + expect, Biome (recommended rules minus noAssignInExpressions and noNonNullAssertion, which the regex-exec loops and deliberate ! use rely on), tsc --noEmit.
