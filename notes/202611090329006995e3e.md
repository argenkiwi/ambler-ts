Spiked @earendil-works/pi-durable, pi-ai and chord 1.5.0 via npm: specifiers in Deno 2.9.8: openNodeSqliteStorage (node:sqlite) works, so no Node fallback was needed. Gotchas: the openai-completions client throws "No API key for provider" unless the provider auth resolves an apiKey, so keyless local hosts (Ollama, LM Studio) must resolve a placeholder like "unused". deno.json needs prefix mappings ("@earendil-works/pi-durable/": "npm:/@earendil-works/pi-durable@1.5.0/") for subpath imports, and the chat task needs --allow-net --allow-read --allow-write --allow-env. The API is experimental so versions are pinned exactly.
