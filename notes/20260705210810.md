Every zettel-* deno task, including zettel-get and zettel-search which never write note content, needs --allow-write on the db path, not just --allow-read. Confirmed by a runtime NotCapable error: DatabaseSync opens the file read-write by default (likely to create/update the WAL or journal), so read-only CLI tools still need write access to .zettelkasten/zettel.db. Registered in deno.json accordingly.
