Replaced six separate zettel-create/get/update/delete/search/link walks (and their individual deno tasks) with a single walks/zettel.ts that accepts a subcommand as its first CLI argument (deno task zettel <action> [args]). A new nodes/zettel-router.ts node reads state.action, switches on it case-insensitively, and transitions to the matching operation node. All six individual walks and their specs were deleted. The deno.json now has a single zettel task with --allow-read --allow-write --allow-net. AGENTS.md, README.md, ambler-zettel SKILL.md, ambler-zettel-init SKILL.md, and the AGENTS.md template asset were all updated to reflect the new subcommand syntax (e.g. deno task zettel search instead of deno task zettel-search).
