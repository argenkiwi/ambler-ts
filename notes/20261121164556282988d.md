Convention adopted from ambler-rs (Result<Outcome, Error>). Failures the walk should react to go through an onError-style edge, usually with an `error` state field. Truly unexpected failures throw, and walk() reports them as WalkError with the node id. Walk entry points exit 1 if the final state has `error`. Before this, clone printed the error and exited 0. init-stop already called Deno.exit(1) itself. Second rule: any node that reads input must route null (closed stdin/Ctrl+D) somewhere other than its own retry edge. llm-check used to return onError -> LLM_CHECK on null, so `deno task chat </dev/null` with no LLM running looped forever. It now has an onQuit edge wired to CHAT_BYE. The Rust Confirm node treats EOF as No for the same reason. Also, start.ts used parseInt, which accepted "3abc" as 3. It now uses Number()+Number.isInteger.
